V5 adds real private instruction-tag admission to the v4 model. `instruction_hit(hart,address,bytes)` returns true only when ALL requested DRAM lines are present in that hart's L1I and no own accepted instruction refill remains pending on them. Other harts' pending instruction/data/vector transactions do not block an existing private Get-only instruction hit.

`touch_instruction(hart,address,bytes,tick)` requires such a hit, updates only private instruction LRU ages, and returns local hit counts for all spanned64B lines. It creates no pending owner, touches no L2 tag, returns no NoC dependencies and supplies no latency. Missing/invalid tags and clock reversal refuse. Caller-side accepted miss ownership still guards its own in-flight refill. FENCE.I invalidates actual tags; no PC or instruction-length response-credit table is needed.

This resolves the model's three-hart convoy for a four-byte instruction at PC mod64=62: once its two lines have returned, its private hit can be consumed while other harts' accepted refills finish. A repeated query cannot create another owner solely because the instruction spans lines. It remains an empirical source-geometry/LRU timing model, not a memory-value, definedness, hardware-state or ±2% certificate.
