The empirical cache helper tracks timing tags for all three harts. It supplies no memory values, definedness bits, service latencies, observed readiness/state, benchmark IDs, PCs, golden cycles, or repetition numbers.

Use `CacheHistory(iris_geometry())`, then `begin({owner,hart,address,bytes,write,model_tick})`. Owners are strictly increasing positive identifiers across all harts. `begin` returns path, L1/L2 hits and misses, dirty victims, sharing/invalidations, active same/other-bank contenders, and `wait_for` owner IDs. Keep those real event dependencies, and call `complete(owner,model_tick)` only at the matching response/functional publication callback. Completing a dependent before its owner is refused. Tags change at accepted intent, which is an explicit approximation; pending same-line dependencies prevent an installed timing tag from hiding unfinished service. Functional bytes and knownness remain in the caller's owned completion callback.

Geometry follows the saved elaboration: harts0/1 L1D 64sets×2ways×64B=8KiB; hart2 L1D64sets×4ways×64B=16KiB; L2fourbanks×512sets×4ways×64B=512KiB. Saved L2 address masks and setBits[8:16] establish bankbits[6:7]. L1 and L2 replacement is explicit LRU, rather than a claim to reproduce source random replacement. Coherence is a timing approximation with private dirty ownership, read forwarding, store invalidation and inclusive L2 victim invalidation. TCM/scratch bank contention uses bit6; L2 uses bits6/7. This is not the frozen source-exact cache/NoC/Serial SDK.

Canonical TCM0/1, per-hart TCM aliases, scratchpad and cacheable DRAM follow the source board map. Hart2 has no TCM alias. Two TCMs are distinct contention domains; local/remote accesses to the same TCM share its domain. Unknown/MMIO addresses are reported UNCACHED and never allocated cache tags. This helper does not grant functional access permission or provide RAM backing for holes. The caller must retain the board's real PMA/PMP, alignment and fault behavior.

Contenders derive only from actually pending accepted requests. There is no guessed active-hart mask, occupancy window or default transaction duration. Requests have a bounded4096B length; callers must split larger operations at their actual memory interface. Cross-line work is counted explicitly. The current API is data-only; instruction caches remain a separate future feature.

The component proof checks30,000 independent accepted-address histories, including all-three-hart dirty sharing and LRU behavior, plus typed lifecycle/address/geometry refusals. It does not establish FPGA cache state, source/image association or timing accuracy. The first failed test expectation is preserved under build/empirical-cache-v1: a dirty L1 writeback refreshed L2 recency, so the test's expected victim was wrong. Clean L2 replacement and dirty victim retention are now checked separately.
