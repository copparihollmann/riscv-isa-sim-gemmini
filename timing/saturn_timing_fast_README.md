# Qualified first Saturn numeric substitution

This keeps the complete configured Saturn runtime reference and substitutes
only the OPU cell's FP8 widening and FP32 FMA arithmetic. The original cell MRF,
index Pipe, integer arithmetic, full write precedence and read mux remain
verbatim. Two source valid stages and result holding registers remain explicit.
All surrounding array/cluster/backend registers, readout enables, queues,
sequencers, hazards, VRF ports, memory unit and FPU ports remain computed by the
saved source. There is no idle skipping, observed-state input or service delay.

The pure numeric call uses the FP8 conversion and SoftFloat library restored
from the immutable combined359 functional manifest. It saves/restores the
caller rounding mode, flags and tininess setting. The OPU has no wired exception
flag output. Legal rounding modes0–4 are qualified; unqualified5–7 fail closed
in this candidate rather than receive an invented result. Existing source tile
definedness limitations and explicit initialization requirements still apply.

The public evaluate/sample/commit API is unchanged in
`build/saturn-timing-fast-v1/sdk/sdk/saturn_timing.hpp`, with the corresponding
static library and executable. Its distinct source identity is
`01be201169d35f8a48f2f0ca4184292d78f31047f36077fffcf16b6764036e55`.
The generated source and exact cone patch are archived in the candidate.
The Rocket model is the unchanged exact reference model; it has no OPU.

Independent cell proof covers262,144 integer cases,262,144 exhaustive FP8
operand pairs,272,404 FP8 sequences/288,317 FP8 MACs,32 consecutive-entry batches,
all16 priorities and the two-edge completion timing. Independent whole-array
proof covers27,134 edges/108,464 output checks,24 complete4096-word scans and
20groups of four consecutive FP8 issues across all4 format pairs and5 rounding
modes, plus INT8 and row/column moves. A wrong one-edge completion variant is
rejected by the same independent cell checker. Corrupted and truncated numeric
corpora are rejected. Existing independent goldens are not generated by Spike.

All12 whole-Saturn actual-reset replays agree with the independent whole-SoC
captures:932,079 source edges and15,127,193 qualified output words, including
EX/MEM/COM kills/replay, every TL beat, hart2 refusal and364 shared-FPU
request/response pairs. Same-edge recovery guards cover35,493 active-prefix
edges;160,000 concurrent numeric calls preserve their caller FP state.

Across three seeds, the real VME active window improves from5.17–5.33k to
23.45–23.59k compute source edges/s, about4.5×. RVV compute reaches23.41–23.95k;
FPComp compute23.58–24.35k. Rocket remains the original model (107–109k for
this run; host variation is not a model speedup). Prefix/reset/boot edges run
before the timed interval; every active guest edge runs. Text I/O is outside
the timer and source debug print formatting remains inside. This is component
speed, not SoC MIPS or a sufficient final compiler iteration performance claim.

The frozen package is layered on the separately frozen full-reference capsule;
both reports and all artifact hashes/modes must verify. Its verifier compares
fresh seed91 stepping directly with that dependency's raw whole-SoC captures,
and reruns the independent cell/array corpora and the wrong-timing mutation:

```sh
python3 timing/saturn_timing_fast_package.py --verify
```

The failed `fast-active-v1` attempt had a host report-field typo after producing
the first measured window; it is preserved. The final `fast-active-v2` receipt
binds the corrected stable script. No native source changed for that correction.
This package does not alter primary Spike, the shared timing engine, Zephyr,
compiler gates, calibration data or FPGA inputs. Whole-SoC/Ethan-image identity
and held-out2% timing remain unqualified.
