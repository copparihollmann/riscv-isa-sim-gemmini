# Explicit input-service evaluator

`export_execute_service.py` creates a distinct closed provider bundle from the
exact retained bridge release. It preserves the old provider, staging engine,
functional extension and feature counts. The legacy evaluator remains usable.
Select the new library and `target.execution_service.version=1` together.

The model consumes explicitly selected array extent, minimum input rows and the
control-case mask from an independent source proof. Each mask bit encodes
`dataflow<<4 | d_garbage<<3 | a_transposer<<2 | b_transposer<<1 | d_transposer`.
Current admission is fenced, conservative weight-stationary single-MUL only.
PRELOAD descriptor retirement, reservations and local-store conflict handling
remain delegated to the retained staging implementation. Unsupported phases and
unknown original prices remain unknown.

For admitted COMPUTE, input occupancy is the selected number of rows at one row
per cycle. Latency adds a separately fitted nonnegative propagation cost. The
row rule is independent of the nominal padded-MAC counter; that original counter
is deliberately unchanged. A row-service proof does not prove mesh completion,
reachable states, output service, bank stalls or packet-level cycle equivalence.

This source release and its synthetic tests issue no timing qualification.
Training must retain original source-group splits, and a frozen model needs its
own live source owner and unchanged held calibration gates. Missing capacity or
attention labels still leave those domains UNKNOWN. Never replace the incumbent
from training error alone.
