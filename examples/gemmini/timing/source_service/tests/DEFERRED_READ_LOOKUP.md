# Native lookup after original device request admission

The selected `Scheduler.scala` drives `directory.io.read.valid` from `alloc_uses_directory` or an MSHR reload. `request_alloc_cases` requires a free eligible MSHR and the directory port; same-set secondary requests reach the directory on reload. It does not perform tag/replacement/coherence classification for every upstream request before obtaining that finite owner.

The opt-in `source_deferred_read_lookup` moves the original device ReaderPacket's existing native memory callback after the existing ten-MSHR/set admission callback. It carries that reservation's retirement token into the original V7 read allocation, avoiding a second allocation. Resident no-probe Gets retain their SourceD-request retirement milestone; other original reads retain full cache-publication retirement. The original packet, response beats, DMA tracker slot and destination row mapping remain intact. Each original packet must fit one cache line; V7 captures exactly one source-owned child. The existing native private-target-probe route may return an indivisible aggregate effect instead of V7. That path retains its original effects and response beats, with the reservation conservatively held through the last actually accepted client D beat. Its separate feature counter explicitly reports this bound; no unrelated fallback cost or silent credit release is introduced.

The source feature `target.posted.read_lookup_after_mshr_admission` counts these actual native callbacks. The focused readout integration control exercises16 original Gets with same-line/set pressure and confirms16 callbacks, ordered acceptance times, preserved destination publication and command completion. SourceD tests separately retain real S2/S3/S4 and bank backpressure. CPU original requests continue through their existing V7 parent/child interface; this change does not pretend CPU private-cache critical-word completion or all CPU classification timing is closed.

This is a protocol ordering change, with no changed memory price or hardware capacity. Exact selected source hashes and public before/after ELF receipts accompany prospective runtime exports.
