This is an experimental calibration from 6,750 actual FPGA region observations. It does not certify the full simulator, source/image association, or ±2% accuracy. The published functional model and frozen exact-source components remain separate.

`split.json` froze 580 training parents and 156 internal-validation parents before fitting. All five trials and all harts remain in the same parent partition. Exact semantic aliases share one partition. Global heldout timings were never read. `parameters.json` was frozen before the internal-validation evaluation. Its SHA256 is `6b161126f1967b879e329e638087f610870dd16a4d0f07c436b0a695e6fce246`.

The feature proxy predicts 5,540 measured regions and explicitly leaves 1,210 unmodeled. Internal validation covers 1,190 represented regions: median absolute error 2.10%, 90th percentile 23.24%, and 49.4% within ±2%. These numbers are for the region feature proxy, not the live simulator. Full signed per-region errors are in `predictions.csv`; family and repetition statistics are in `fit-report.json` and `repetition-variance.json`.

The first fit uses source operation counts, DLEN beats, actual physical retired-instruction counts, memory paths, and bank-sharing features. It never predicts from case IDs, PCs, trial numbers, or golden cycle tables. Physical instret is an offline scalar-work proxy: a live model must provide corresponding executed instruction/pipeline features. All fits are nonnegative, grouped by semantic/hart median, and weighted by relative error. Rank-deficient coefficients do not identify individual physical unit latencies.

`region_intercept_cycles` is a per-region nuisance term. It MUST NOT be charged at every instruction. The flat `fixture-draft-v1/residual.fixture` contains none of these intercepts; it is an unqualified integration draft for added residual stalls. Scalar-work subtraction does not establish physical operation latency when scalar control overlaps accelerator work. The engine must validate its scheduling interpretation before these coefficients become a runtime calibration.

Large failures remain visible. The first FP16 block is underpredicted by 89–95% across all repetitions, consistent with unmodeled instruction/cache history. Some tile moves also have large errors. Cached DRAM routes do not identify separate L1/L2/serial-TL/DRAM miss costs. Shared-memory synchronization, interrupts, atomic contention, branch-miss penalties, and heldout Zephyr timings are not calibrated here.

A separate `../empirical-stream-v1` capacity proxy estimates aggregate memory line service. It generalizes poorly (17.4% internal-validation median error) and is not a physical cache-trace reconstruction. Preparation metadata approximates counts offline; runtime warm/cold state must come from actual tag/history evolution. No FASED 30-cycle value is converted into a CPU or whole-SoC latency.
